# goldpepp

Interfaccia web **GoldPEPP · zer0day**.

## Stato

- `index.html`: pagina pubblicata nel branch `main` con il pulsante centrale **PRIEMM CCA**.
- **Anteprima grafica**: il pulsante non esegue modifiche alla console.
- **Non verificato su PS4**: l'interfaccia non equivale a una procedura di avvio funzionante.

## Pubblicare su GitHub Pages

Nel repository apri **Settings → Pages**; in *Build and deployment* scegli **Deploy from a branch**, branch **main**, cartella **/(root)** e salva.

L'indirizzo atteso, una volta attivato Pages, è:
https://zer0days-op.github.io/goldpepp/
